# Job Search Tracker

Live dashboard of my job search and open-source contribution campaign: **https://cloudcorprecords.github.io/job-search-tracker/**

- **Job applications**: every application I've sent, with status, channel, comp and notes, plus activity by day and a breakdown by status.
- **Open-source PRs**: issues I've vetted and the PRs I've opened, by repo and pipeline stage.

Everything is searchable, filterable and sortable.

## How it updates

Job applications: the page is a static site with no build step and no backend. On every visit (and every 5 minutes while the page is open) it reads the jobs Google Sheet as CSV in the browser, so new rows show up as soon as they're logged.

Open-source PRs: the page loads `data/prs.json` from this repo. That file is regenerated by [`tools/build-prs-data.py`](tools/build-prs-data.py), which takes the tracked row list from the PR tracker sheet (read only) and then reads every issue's own state and every linked pull request's own state from the GitHub API. The two are kept as separate fields: the "Issue status" column always shows the issue itself, and the "Our PR" column shows the PR number with its own outcome (open, merged with date, or closed unmerged with date). To refresh, run the script and commit the result:

```
python3 tools/build-prs-data.py
```

Data sources for the jobs tab are set in [`config.js`](config.js):

- `jobsCsv`: a "Publish to web" CSV link (File → Share → Publish to web → pick the tab → CSV).
- Otherwise it falls back to the sheet ID, which works when the sheet is shared as "anyone with the link can view".
